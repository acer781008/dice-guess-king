# 骰子猜猜王｜正式多人連線版 V1

這是正式上線用的 Node.js + Socket.IO 專案。不同手機、不同電腦可連到同一個網址與房間。

## 已完成
- 正式伺服器房間（6 位數房號）
- 主控密碼登入
- 主控建立新房號
- 玩家分享網址自動帶 room
- 玩家名稱不可重複
- 開賽倒數期間可加入，正式開始後鎖房
- 5 種遊戲模式
- 猜號碼「不看順序」使用數量配對
- 猜號碼「看順序」使用位置配對
- 伺服器產生骰子與計分
- 即時多人同步
- 即時排行榜 / 最終排名
- 玩家重新整理後可用 token 回到原玩家
- 排程開賽、立即開始、暫停、結束

## 本機測試
需要 Node.js：

```bash
npm install
npm start
```

瀏覽器開啟：
- 主控：http://localhost:3000/admin.html
- 玩家：由主控按「複製玩家連結」取得

預設本機管理員密碼：`1234`
正式部署請設定環境變數 `ADMIN_PASSWORD`。

## Render 部署
專案已包含 `render.yaml`。
將整個專案放到 GitHub 後，可在 Render 建立 Web Service，設定：
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `ADMIN_PASSWORD` = 你要的正式主控密碼

## 目前正式版 V1 的資料保存方式
房間目前存在伺服器記憶體中。伺服器重新啟動後房間會重置。
下一階段若要長期保存活動、玩家紀錄與歷史排行榜，可再接資料庫。
